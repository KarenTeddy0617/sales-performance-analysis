# Sales Performance Analysis (Pandas Project)

## Overview
This project analyzes sales performance using a retail dataset.  
The goal is to extract business insights through data cleaning, aggregation, and visualization.

## Dataset
- Source: Kaggle Superstore Dataset
- Note: The dataset did not contain order dates.
  A synthetic `Order_Date` (2025) was generated for trend analysis.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Key Analysis
- Category-wise sales analysis
- Region-wise sales performance
- Monthly sales trends (synthetic dates)
- Profitability insights

## Key Insights
- Sales performance varies across categories and regions.
- Monthly trends reveal demand fluctuations.
- Data preprocessing plays a critical role in analysis.

## How to Run
1. Clone the repository
2. Open `sales_analysis.ipynb`
3. Run all cells
